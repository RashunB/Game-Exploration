# 0001: Unreal Engine 5.8 over 5.7

- Status: accepted
- Date: 2026-10-23

## Context

The plan first targeted 5.7. Claude Code drives the editor through Epic's `unreal-engine-skills-for-claude-code` plugin, which depends on the Unreal MCP editor plugin (`ModelContextProtocol`, `AllToolsets`). That plugin ships with 5.8.

## Decision

Build on UE 5.8 (launcher build, 5.8.4 at last build). No engine upgrade is planned before Early Access.

## Alternatives

- Stay on 5.7 and drive the editor without MCP: every Blueprint subclass, DataAsset, Input asset, and level edit would be manual work for Rashun, since Claude can't edit binary assets as text.
- 5.7 with a community MCP plugin: not considered in the record.

## Consequences

Editor automation over MCP is available, at the cost of Experimental plugins (`PLAN.md` section 3). Some marketplace assets list only older engine versions and need a seller's confirmation before buying (`PLAN.md` section 7). Visual Studio requirements follow 5.8.

## Revisit if

Epic ships a 5.x or 6.0 release with a fix the project needs, or the MCP plugins prove too unstable to rely on.

## Sources

`PLAN.md` section 2 and the 2026-10-23 revision history entry. `PLAN.md` also notes 5.8 is expected to be the last 5.x release.
